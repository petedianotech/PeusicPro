# PeusicPro

A next-generation native Android music player app built with Kotlin, Jetpack Compose, Material 3, and stunning immersive gradient UI design.

## Features
- **Immersive Gradient Now Playing UI**: Dynamic animated glowing gradients that react to your music.
- **Material 3 Design**: Clean, modern, and adaptive interface.
- **High-Performance Audio**: Built with AndroidX Media3 for robust local playback and background service support.
